# Aurelia House — Hospitality Website Template

## Short description

A premium React and Firebase hospitality template for boutique hotels, resorts, restaurants, and event venues.

## Features

- Responsive rooms, room details, booking, restaurant, table reservation, room service, events, gallery, contact, legal, and 404 pages.
- Firebase-backed public submissions, email/password admin sign-in, protected operations desk, and Firestore rules.
- Centralized buyer configuration and setup documentation.

## Stack

React 19, Vite 8, Tailwind CSS 4, React Router 7, Firebase 12. Requires Node.js 20.19+ or 22.12+ and a Firebase project for live forms/admin features. Version 1.0.1.
